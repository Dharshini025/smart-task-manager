# Smart Task Manager
A To-Do List web application built using Python and Streamlit.
## Features
- Add tasks
- Edit tasks
- Delete tasks
- Priority-based tasks
- Due dates
- Every day tasks
- Task completion checkbox
- Lavender themed UI
## Technologies Used
- Python
- Streamlit
## Run the Project
Install Streamlit:
pip install streamlit
Run the app:
streamlit run app.py
